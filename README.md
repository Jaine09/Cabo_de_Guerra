# Força ou Queda - Jogo de Cabo de Guerra (JavaScript)

Este é um jogo de Cabo de Guerra temático, desenvolvido utilizando HTML, CSS e JavaScript durante a Imersão Dev da Alura. Nele, você escolhe 3 personagens para formar seu time e tenta vencer uma disputa de força contra um time de 3 vilões aleatórios!

## Como Jogar

1.  Clique no botão **"Escolha 3 jogadores para seu time:"**.
2.  Serão solicitados, via `prompt`, os nomes de **três personagens** que farão parte da sua equipe. Digite o nome de cada um e pressione "OK".
3.  O computador formará automaticamente um time de três vilões aleatórios de uma lista predefinida.
4.  Ao final da escolha dos seus personagens e da definição dos vilões, uma mensagem em `alert` informará se o seu time venceu ou perdeu a disputa de "cabo de guerra", com base na força total aleatória de cada equipe.
5.  Para jogar novamente, simplesmente recarregue a página.

## Funcionalidades

* Interface gráfica simples com um título temático ("Força ou Queda") e um logo da Imersão Dev.
* Permite ao jogador escolher 3 personagens para o seu time através de prompts.
* Seleciona aleatoriamente 3 vilões de uma lista predefinida para o time adversário.
* Calcula uma força total aleatória para cada time (personagens e vilões).
* Determina o vencedor da disputa comparando a força total dos dois times.
* Exibe o resultado da partida através de um `alert`, informando a força do seu time e, em caso de derrota, a força do time adversário.
* Possibilidade de jogar novamente recarregando a página.

## Tecnologias Utilizadas

* **HTML:** Estrutura da página web e elementos interativos (botão).
* **CSS:** Estilização visual da página, incluindo um background temático e formatação dos elementos.
* **JavaScript:** Lógica principal do jogo, incluindo a coleta dos nomes dos personagens, a seleção aleatória dos vilões, o cálculo da força e a determinação do vencedor.
